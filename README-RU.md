# Cossacks II — Unofficial Restoration

[English](README.md) · [Поддерживаемые файлы](docs/SUPPORTED.md) · [Сборка](docs/BUILD.md) · [Проверки](docs/VERIFICATION.md)

Бесплатный неофициальный патч для **проверенной GOG-версии Cossacks II: Battle for Europe**. Требуется ваша оригинальная игра. [Купить Cossacks II Anthology на GOG](https://www.gog.com/en/game/cossacks_ii_anthology).

Это предварительный выпуск. Установка, откат и изолированные контракты исправления проверены без запуска игры. Ранее пользователь успешно провёл короткие сессии с тем же исправленным игровым EXE. Игровая проверка нового установщика ещё предстоит; универсальное устранение всех проблем не заявляется.

## Установка

1. Закройте игру и DxWnd. Для первого испытания удобно использовать отдельную копию оригинальной игры.
2. Скачайте `CossacksII-Unofficial-Restoration-0.1.0-preview-setup.exe` и `SHA256SUMS.txt` из [Releases](https://github.com/Klopi746/cossacks-ii-unofficial-restoration/releases). При проверке загрузки сравните SHA-256.
3. Откройте мастер, выберите русский или английский язык и папку с `engine.exe`. При наличии записи GOG путь определяется автоматически; папку можно выбрать вручную.
4. Выберите разрешение рендеринга, подтвердите наличие оригинальной игры и нажмите «Установить». По умолчанию предлагается разрешение основного монитора; доступны также 1920×1080, 2560×1440 и 1280×720.
5. Запустите игру самостоятельно через ярлык **Cossacks II — Unofficial Restoration**. После установки игра автоматически не запускается.

Существующий ярлык сохраняется; при совпадении имени создаётся отдельный с номером. Мастер работает с локальными файлами игры, не запрашивает административные права и не меняет глобальные настройки видеокарты. Нужна папка, доступная для записи.

**Установка работает без интернета.** DXVK, DxWnd 2.06.16, нужные DLL, наш патчер, лицензии и соответствующие исходники DxWnd уже внутри setup. Отдельно искать компоненты, устанавливать Python или PowerShell 7 не требуется. ZIP исходников доступен также отдельным файлом релиза. [Подробности состава и лицензий](THIRD_PARTY.md).

## Что изменяется

- Таблицы формирований расширяются с 64 до 128 строк в обоих найденных потребителях. Размеры буферов, шаги и лимиты согласованы. Проверки границ и предупреждение о превышении ёмкости сохранены; пустая строка `0xFFFF` пропускается до обращения к данным формирования.
- DXVK 3.1.1 x86 подключается через игровой импорт `X3D8.DLL` и соответствующий D3D9. Профиль: лимит 60 FPS, доступная память 1024 и `presentInterval=0`.
- DxWnd создаёт Borderless на основном мониторе. Меню заполняет окно за счёт растяжения исходного 4:3; это не заново нарисованный интерфейс 16:9. Наш лаунчер не переключает физический видеорежим Windows.
- Перед заменой создаются резервные копии и манифест с хешами до/после в `.c2-restoration/state.json`.
- Обычный запуск сохраняет резервный quiet-log: только `log.txt` временно получает ReadOnly, после выхода возвращается прежний бит атрибута. Незавершённая собственная транзакция восстанавливается при следующем запуске или удалении. Новое содержимое журнала, если появилось, не уничтожается.
- `Restoration-Diagnostics.cmd` в папке игры разрешает запись игрового журнала и показывает небольшой HUD DXVK с FPS/версией. Для проверки настоящего исправления используйте этот режим.

Игровые моды, изменение баланса, карты, сторонний модернизированный движок, готовый `engine.exe` и установщики игры в пакет не входят.

## Удаление и восстановление

При закрытой игре откройте `Restoration-Uninstall.cmd` или мастер установки, выберите ту же папку, перейдите к странице компонентов и нажмите «Удалить / восстановить». Исходные файлы возвращаются из проверенных копий. `Save`, `Players` и посторонние файлы не удаляются.

Если файл, которым управлял патч, изменён после установки, его текущее содержимое сначала сохраняется отдельно в `.c2-restoration/conflicts/`, затем возвращается исходный файл. Изменённый пользователем ярлык сохраняется. В результате указано число конфликтов. Резервные копии, история и журналы остаются для проверки; работающий EXE обслуживания также остаётся, если Windows удерживает его открытым. После возврата исходных игровых файлов патч удалён, даже если папка восстановления сохранена.

Повторная установка без изменений только проверяет файлы. Если появились правки пользователя, мастер отказывается их перезаписывать. Для другого разрешения удалите патч и установите заново: прежняя история сохранится в `.c2-restoration-history-*`. При повреждённой или отсутствующей резервной копии откат останавливается до изменения файлов и сообщает проблему. Сохраняйте собственную копию игры до окончания ручных испытаний.

## Требования и ограничения

- Windows 11 или Windows 10 22H2, x64, с уже имеющимся .NET Framework 4.8+. Другие ОС не проверены. [Таблица Microsoft](https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements).
- Видеокарта и драйвер, способные запускать DXVK 3.1.1, включая 32-битную поддержку Vulkan. Установщик не ставит драйверы или Vulkan. [Требования DXVK](https://github.com/doitsujin/dxvk/wiki/Driver-support); сам проект DXVK [официально не поддерживает Windows](https://github.com/doitsujin/dxvk/wiki/Windows).
- Около 150 МБ сверх установленной игры для компонентов, исходных копий, EXE обслуживания и журнала. Повторные установки и диагностика требуют дополнительного места.
- Принимаются только точные исходные хеши из [SUPPORTED.md](docs/SUPPORTED.md). Napoleonic Wars, Steam, другие GOG EXE, Windows on ARM, Wine и multiplayer этим выпуском не поддерживаются.
- Файловые операции с пробелами и кириллицей проверены. Реальный запуск DxWnd зависит от системной кодовой страницы Windows либо доступного короткого пути 8.3. Если путь невозможно представить, лаунчер откажется запускать игру; используйте папку из латинских символов. Игра из пути с кириллицей ещё не проверялась.
- EXE установщика не подписан. Не отключайте защиту Windows и не добавляйте исключения антивируса ради запуска. При необходимости изучите исходники и выполните собственную сборку.

Короткая ручная проверка через `Restoration-Diagnostics.cmd`: меню и клики → сражение с ботом, казарма и формирование → 5–10 минут боя, дороги и захват деревни → сохранение, выход, повторный запуск и загрузка → Alt+Tab и штатный выход. В свежем разрешённом `log.txt` должны появиться обычные записи без повторяющегося `no>=MaxOf`. Точные FPS, все нации, долгие бои и совместимость сохранений пока требуют ручной проверки.
